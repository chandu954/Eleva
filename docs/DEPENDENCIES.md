## Keeping it current

- `pnpm-workspace.yaml` → `auditConfig.ignoreGhsas` lists accepted advisories;
  every entry needs a justification comment and a quarterly review.
- Dependabot (`.github/dependabot.yml`) opens updates for direct dependencies.
- The weekly `dependency-freshness` workflow reports packages two or more
  majors behind their latest release; handle each major deliberately rather
  than ignoring the report.
- `pnpm outdated` shows the full lag list against the registry.
- Run `pnpm report:dependency-health` after changing `package.json` or
  `pnpm-lock.yaml` so the resolved and transitive counts above stay accurate.
